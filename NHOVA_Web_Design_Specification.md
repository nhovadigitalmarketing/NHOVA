# NHOVA — Web Design Specification

## Brand
**NHOVA**  
**Turning Attention Into Impact**

**Category:** Digital Marketing  
**Location:** Jaipur, Rajasthan, India

NHOVA is a full-stack digital marketing and creative growth agency combining strategy, branding, content, performance marketing and technology.

---

## 1. Design Direction

Create a premium, editorial, modern and high-conversion experience.

Design principles inspired by:
- Apple — clarity and typography
- Linear — product-quality UI and motion
- Stripe — trust and conversion
- Framer — interaction quality
- Vercel — minimalism
- Ediskool — storytelling and conversion flow
- Awwwards-quality agency experiences

Do not copy any reference website.

Use the uploaded NHOVA logo and red/black artwork as the primary brand references.

---

## 2. Brand Identity

### Logo
Use the uploaded NHOVA logo exactly.

Do not redraw, distort, replace, recolor or change its proportions.

Use it in:
- Navbar

- Favicon
- Client portal
- Admin interface

> **TURNING ATTENTION INTO IMPACT**

## 3. Color System

| Token | Value |
|---|---|
| Primary Background | `#000000` |
| Secondary Background | `#050505` |
| Surface | `#0B0B0B` |
| Card | `#111111` |
| NHOVA Red | `#FF1A1A` |
| Bright Red | `#FF2B2B` |
| Deep Red | `#8B0000` |
| White | `#FFFFFF` |
| Secondary Text | `#B5B5B5` |
| Muted Text | `#777777` |
| Border | `rgba(255,255,255,0.10)` |
| Red Border | `rgba(255,30,30,0.35)` |

Recommended ratio: 80% black, 15% white/grey, 5% red.

---

## 4. Typography

Display: Bebas Neue / Anton / Oswald or equivalent premium condensed font.

Body: Inter.

Navigation: Inter Medium.

Use very large headlines, short copy, strong contrast, tight editorial hierarchy and generous whitespace.

## 28. Motion System

Preferred:
- GSAP
- Framer Motion
- Lenis

Use:
- Text reveal
- Image reveal
- Mask reveal
- Scroll reveal
- Parallax
- Magnetic buttons
- Number counters
- Hover interactions
- Page transitions
- Section transitions

Motion must be smooth, premium, purposeful, fast and cinematic.

Target 60 FPS. Support reduced motion. Never over-animate.

## 30. Responsive

Support:
- 1440px+
- 1280px
- 1024px
- 768px

- Simple navigation

- Touch-friendly controls
- Optimized images
- Reduced motion

## 31. Accessibility

Target WCAG AA.

Implement:
- Semantic HTML
- Keyboard navigation
- ARIA labels
- Focus states
- Correct contrast
- Accessible forms
- Reduced-motion support

## 33. Performance

Target **95+ Lighthouse**.

Use:
- Image optimization
- WebP/AVIF
- Lazy loading
- Code splitting
- Font optimization
- Video optimization
- Caching

Do not sacrifice performance for visual effects.

---

## 34. Content Rules

Never use:
- Lorem ipsum
- Fake clients
- Fake awards
- Fake testimonials
- Fake statistics
- Fake revenue
- Fake ROAS
- Fake logos

When information is unavailable, use clearly editable placeholders.
